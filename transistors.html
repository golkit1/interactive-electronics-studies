טרנזיסטור כמתג Transistor as a Switch

מבוא Introduction

טרנזיסטור (Transistor) הוא מתג חשמלי. במקום אצבע שלוחצת על כפתור, זרם קטן פותח וסוגר אותו.

לטרנזיסטור שלוש רגליים:

  • בסיס (Base): הידית ששולטת במתג.
  • קולט (Collector) ופולט (Emitter): דרכם עובר הזרם הגדול, למשל לנורה או למנוע.
זרם קטן בבסיס  ←  זרם גדול בין הקולט לפולט

יש שני סוגים:

1NPN

לחצו והחזיקו את הכפתור. זרם קטן נכנס לבסיס, הטרנזיסטור נסגר כמו מתג, והנורה נדלקת.

זרם קטן (בבסיס)זרם גדול (בנורה)
למה יש נגד של 10k?

כשהכפתור לא לחוץ, הנגד מחבר את הבסיס לאדמה (GND). כך הטרנזיסטור נכבה בוודאות ולא "מהבהב" מרעשים.

למה יש נגד של 1k לפני הבסיס?

הבסיס צריך רק זרם קטן. הנגד שומר שלא ייכנס אליו יותר מדי ושהטרנזיסטור לא יישרף.

2PNP

כאן הכול הפוך: הפולט מחובר לפלוס, והטרנזיסטור נדלק כשהבסיס מחובר לאדמה (GND). כשלוחצים, הכפתור מושך את הבסיס למטה והנורה נדלקת.

זרם קטן (בבסיס)זרם גדול (בנורה)
למה הנגד של 10k מחובר לפלוס?

כשהכפתור לא לחוץ, הנגד מחזיק את הבסיס בפלוס. כך טרנזיסטור PNP נשאר כבוי והנורה לא דולקת.

3דעיכה עם קבל LED Fade Out

הוספנו קבל (Capacitor) ליד הבסיס. כשלוחצים, הקבל מתמלא. כשעוזבים, הקבל מתרוקן לאט דרך הבסיס, והנורה דועכת בהדרגה.

קבל גדול יותר מחזיק יותר חשמל, ולכן הנורה דועכת לאט יותר.

4מנוע וארדואינו Motor & Arduino

מנוע צריך הרבה יותר זרם ממה שהארדואינו (Arduino) יכול לתת. לכן הארדואינו רק שולט בבסיס, והטרנזיסטור מעביר את הזרם הגדול למנוע.

analogRead: PWM:

הארדואינו מדליק ומכבה את הטרנזיסטור מהר מאוד. ככל שהחלק הדלוק ארוך יותר, המנוע מסתובב מהר יותר. השיטה נקראת PWM (Pulse Width Modulation).

למה יש דיודה ליד המנוע?

כשמנוע נכבה הוא יוצר לרגע קפיצת מתח. הדיודה (Diode) מעבירה אותה בחזרה למנוע ומגינה על הטרנזיסטור.

הקוד 
const int potPin = A0;
const int motorPin = 3;
const int threshold = 2;

int potValue = 0;
int pwmValue = 0;
int prevPWM = 0;

void setup() {
  pinMode(motorPin, OUTPUT);
  Serial.begin(115200);
}

void loop() {
  potValue = analogRead(potPin);
  pwmValue = map(potValue, 0, 1023, 0, 255);

  if (abs(pwmValue - prevPWM) > threshold) {
    analogWrite(motorPin, pwmValue);
    Serial.print("PWM ");
    Serial.println(pwmValue);
    prevPWM = pwmValue;
  }
}

הקוד קורא את הנגד המשתנה (0 עד 1023), ממיר לערך PWM (0 עד 255) ושולח אותו לרגל 3.
